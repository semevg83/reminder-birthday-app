# reminder-birthday-app
Android app for reminders and birthdays, with a simple mobile UI and project structure ready for Android Studio.

## Project purpose
This project is a starter Android application for:
- birthday reminders
- task reminders
- quick daily planning

## Tech stack
- Kotlin
- Android SDK
- Material Components
- ViewBinding

## Run locally
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Select an Android device or emulator.
4. Run the app.

## Notes
This repository contains the base project structure and app files needed to start development.
